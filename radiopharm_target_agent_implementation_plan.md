# radiopharm-target-agent — Implementation Plan

A multi-agent system for radiopharmaceutical target assessment and prioritisation. Built under `txgemma_demo/radiopharm-target-agent/` as an independent Poetry project, reusing components from `drug-discovery-agent` and `clinical-research-synthesizer`.

**What it does:** given one or more candidate targets, an indication, and an isotope context, it gathers tumour-vs-normal expression evidence, single-cell compartment localisation, the clinical trial landscape, full-text literature, and target dynamics (internalisation, shedding, accessibility), then produces an auditable, deterministically scored prioritisation briefing.

**What it does not do:** patient-specific dosimetry, radiochemical or chelator stability, absolute receptor density (Bmax), and radiation transport physics. These require biophysical engines and wet-lab assays and are permanently out of scope.

---

## 1. Design Principles

Five decisions constrain everything below. Accept or amend them before writing code.

**1.1 Evidence is typed, not prose.** Every specialist returns validated `Claim` objects, not text the coordinator interprets. This is a change from the ported components, which currently emit briefing prose.

**1.2 A measured claim without a source cannot be constructed.** Enforced by Pydantic validation, not by prompt instruction. An unsourced assertion raises at construction time rather than flowing into the scorecard.

**1.3 Scores are computed in Python, never generated by a model.** The LLM extracts evidence and writes narrative around fixed numbers. `scorer.py` produces every numeric value and the rank order. Same inputs must give byte-identical scores.

**1.4 Missing data is not zero.** `not_detected` (source consulted, target absent) and `not_measured` (source doesn't cover this tissue) are distinct states with different scoring consequences. Conflating them under-calls organ-at-risk toxicity.

**1.5 Enrichment models are off the critical path.** Gemini and the deterministic REST tools are required. TxGemma, MedGemma and Cell2Sentence are enrichment: their failure produces a labelled `unavailable` field and the run completes.

## 2. Architecture

### 2.1 Orchestration

The workflow is a fixed five-step pipeline, so it uses a `SequentialAgent` spine rather than LLM-driven `sub_agents` transfer, which would execute steps inconsistently and defeat reproducibility.

```
radiopharm_coordinator  (SequentialAgent)
│
├── 1. planner              LlmAgent
│       resolve gene symbols, set indication,
│       REQUIRE isotope_context, emit run plan
│
├── 2. gather               ParallelAgent
│       ├── expression_specialist
│       ├── clinical_specialist
│       └── literature_specialist
│
├── 3. target_biology_specialist   LlmAgent
│       consumes gather output as context
│
├── 4. scorer               deterministic Python — not an agent
│
└── 5. writer               LlmAgent
        narrative constrained to values already
        present in EvidenceBundle and Scorecard
```

The three gather specialists are mutually independent and are the latency bottleneck; running them concurrently is the largest available speed win. Target biology runs afterwards because it needs the expression result.

### 2.2 The evidence contract

```python
# schemas.py

class SourceRef(BaseModel):
    kind: Literal["gtex", "hpa", "uniprot", "c2s", "ctgov", "pubmed", "pmc", "txgemma"]
    identifier: str          # PMID, NCT ID, HPA antibody ID, dataset ID, query hash
    retrieved_at: datetime
    version: str             # GTEx release, HPA version, CT.gov query date

class Claim(BaseModel):
    field: str
    value: float | str | None
    unit: str | None
    status: Literal["measured", "not_detected", "not_measured", "unavailable"]
    evidence_tier: Literal[
        "protein_quant", "protein_ihc", "bulk_rna", "sc_rank", "literature", "absent"
    ]
    sources: list[SourceRef]
    confidence: Literal["high", "medium", "low"]
    caveats: list[str] = []

    @model_validator(mode="after")
    def measured_requires_source(self):
        if self.status == "measured" and not self.sources:
            raise ValueError(f"measured claim '{self.field}' has no source")
        return self

class EvidenceBundle(BaseModel):
    target: str
    gene_id: str
    indication: str
    isotope_context: Literal["Lu-177", "Ac-225", "Ga-68", "I-131", "Y-90", "Tb-161", "Pb-212"]
    expression: dict[str, Claim]
    oar_panel: dict[str, Claim]
    single_cell: dict[str, Claim]
    clinical: list[TrialRecord]
    literature: list[LiteratureFinding]
    target_biology: dict[str, Claim]
    tractability: dict[str, Claim]
    provenance: RunProvenance
```

`evidence_tier` exists because RNA is standing in for protein throughout. Transcript-level evidence caps the achievable selectivity score; protein evidence lifts it.

### 2.3 Scoring

`scorer.py` is pure, unit-tested, and takes `(EvidenceBundle, isotope_context, weights)`.

| Axis | Input | Isotope-modulated |
|---|---|---|
| Tumour selectivity | T/N ratio, capped by evidence tier | no |
| OAR safety margin | named organ panel, radiosensitivity-weighted | yes |
| Malignant-cell specificity | C2S compartment assignment | no |
| Heterogeneity penalty | % positive malignant cells, dispersion | **yes** — heavier for beta than alpha (cross-fire range) |
| Internalisation suitability | literature/TxGemma finding | **yes** — matters more for residualising Lu-177 |
| Shedding penalty | soluble ECD / serum sink evidence | no |
| Clinical pipeline maturity | trial phase and status distribution | no |
| Tractability | binder existence, ECD length, radioligand precedent | no |

Weights live in a versioned `weights.yaml`. Not in code, not in a prompt.

Any axis whose inputs are all `not_measured` or `unavailable` returns `None` and the scorecard reports "score withheld — insufficient evidence" rather than a mid-range default.

## 3. Component Sourcing

| Component | Origin | Reuse | New work |
|---|---|---|---|
| `clinical_specialist/` | `clinical-research-synthesizer` → Clinical Trial Specialist | `search_trials`, `get_eligibility_criteria_from_api`, agent + prompt scaffolding | ~15% — isotope filter, modality classification, NCT round-trip validator, imaging-positivity threshold extraction |
| `literature_specialist/` | `clinical-research-synthesizer` → Literature Researcher, plus `drug-discovery-agent` → `fetch_pubmed_articles` | `pmc_search`, `extract_pdf_text_from_url`, `summarize_paper`, numbered-citation briefing format | ~25% — radiopharm extraction schema, species labelling, citation-or-abstain guard, pypdf swap |
| `target_biology_specialist/` | `drug-discovery-agent` → Compound Analyzer | TxGemma Chat plumbing, Vertex client | ~50% — full re-prompt for target biology, UniProt tool, ligand tractability |
| `expression_specialist/` | none | — | 100% — the core build |
| Coordinator | `clinical-research-synthesizer` → Research Coordinator | briefing contract, citation numbering, explicit gap identification | ~40% — Sequential+Parallel spine, scoring extracted |

`medical-research` contributes the multi-model routing *pattern* only. Its `predict_bbb_crossing` is irrelevant to radioligands, and it has no retrieval tools or planning layer. Do not import from it.

**On `predict_toxicity.py`:** TxGemma ClinTox is a SMILES-based small-molecule model. Most radioligand vectors are peptides, antibodies or affibodies — outside its training distribution — and it describes the ligand, not the target. Gate it behind an explicit "small-molecule ligand SMILES supplied" condition, label its output as ligand-level, and exclude it from every scorecard axis at the schema level.

## 7. Build Phases

Each phase has a binary exit gate. Do not begin the next phase until it passes.

### Phase 0 — Foundations

- `schemas.py` with `Claim`, `SourceRef`, `EvidenceBundle`, `Scorecard`.
- `provenance.py`: version stamping and startup endpoint health check, reported at the top of every brief.
- `guards.py`: NCT and PMID round-trip validators, citation-or-abstain enforcement.
- Corrected `pyproject.toml` and `.env.example`.
- Freeze the control panel with dated reference answers.

**Exit:** a unit test confirms `Claim(status="measured", sources=[])` raises `ValidationError`.

### Phase 1 — Port the proven components

Lowest risk, immediately demonstrable, and it establishes the citation contract everything else conforms to.

- Port `clinical_specialist` and `literature_specialist` from `clinical-research-synthesizer`, rewired to emit `Claim` objects.
- Add isotope filter (Lu-177, Ac-225, Ga-68, I-131, Y-90, Tb-161, Pb-212) and modality classification (therapy / diagnostic / ADC / cell therapy).
- Add NCBI API key and backoff; swap PyPDF2 for pypdf.
- Add the radiopharm extraction schema: ORR, PFS, OS, MTD, absorbed dose in Gy/GBq by organ, dosimetry method, species label.
- Record frozen API fixtures for the control panel.

**Exit:** every returned NCT ID and PMID resolves on re-fetch (100%, automated). Diagnostic-only PET trials are correctly labelled, not counted as radioligand therapy. A rodent dosimetry paper is labelled `species: mouse`. A target with no trials returns empty with an explicit statement.

### Phase 2 — Expression specialist

The core build and the most use-case-critical component.

- `hpa_gtex_expression.py`: gene resolution with alias disambiguation, GTEx normal profile, HPA normal IHC with antibody reliability score surfaced, HPA Pathology Atlas for the tumour side, T/N with provenance and caveats attached.
- `oar_panel.py`: named organ checklist — kidney cortex, bone marrow, salivary gland, lacrimal gland, liver, spleen, GI tract, lung, brain. Emits `measured` / `not_detected` / `not_measured` per organ and routes `not_measured` organs to the literature specialist as a mandatory sub-query.
- `uniprot_annotations.py`: membrane topology, ECD length, known soluble isoforms.

**On the tumour side:** HPA's Pathology Atlas carries TCGA-derived RNA and cancer IHC, so a separate GDC/Xena connector is not required at this stage. But every T/N ratio must carry its caveats — IHC is semi-quantitative and antibody-dependent, and TCGA bulk includes stromal and immune admixture, which inflates apparent tumour expression for stromal targets.

**Exit:** `lacrimal_gland` and `bone_marrow` return `not_measured`, never `not_detected` or `0`. GAPDH fails selectivity. MKI67 fails the membrane gate. `FOLH9` abstains. `"PSMA"` either prompts for disambiguation or resolves to FOLH1 with an explicit note that `PSMA1–7` were excluded. Three identical queries return byte-identical payloads.

### Phase 3 — Single-cell

Highest technical risk: a generative model producing gene ranks can produce a confident rank for a gene absent from the dataset.

- `cell2sentence_analyzer.py` with both the Vertex endpoint path and a local AnnData rank fallback, plus a concordance check between them (Spearman ≥0.7, else flag low-confidence).
- Membership check against the atlas *before* calling the endpoint.
- Dataset registry: which atlas per indication, with n cells, n patients, and cell-type annotation provenance.
- Heterogeneity as structured numerics: % positive malignant cells, dispersion, bimodality flag.

**Exit:** FAP in a pancreatic atlas returns fibroblast/CAF dominance and *not* malignant ductal cells. EPCAM returns malignant epithelial. PTPRC returns immune only. FOLH1 in a kidney atlas returns proximal tubule. A gene absent from the atlas returns `not_present_in_dataset` with no rank.

**Decision point at phase end:** if the C2S endpoint proves unreliable for quantitative claims, ship with the local scRNA fallback as source of record and use C2S for narrative only. Decide here, not later.

### Phase 4 — Target biology

- Re-prompt TxGemma Chat for internalisation, shedding and topology, with citation-or-abstain enforced in `guards.py` rather than in prose.
- `ligand_tractability.py`: repurpose `identify_compound` and pubchempy for binder existence and radioligand precedent.
- Gate `predict_toxicity.py`; exclude from scoring at the schema level.

**Exit:** MKI67, TP53 and MYC all return `cell_surface: FALSE` and terminate. FOLH1 returns type II single-pass; SSTR2 returns 7TM GPCR. MSLN, ERBB2, CEACAM5 and MUC16 all return shedding-reported with citations; DLL3 returns minimal. Any quantitative claim without a citation is refused, not stated.

### Phase 5 — Scorer and coordinator

- `scorer.py` and `weights.yaml`.
- Rewrite `agent.py` to the Sequential+Parallel spine.
- Strip the rubric out of `prompt.py`; it retains only planner and writer prompts.

**Exit:** five identical runs produce identical scores. Raising kidney expression 10× in the evidence object lowers the OAR safety sub-score and leaves other sub-scores unchanged. FOLH1 ranks far above GAPDH and MKI67, with the correct *failure reasons* stated for each. The same target under Lu-177 and Ac-225 produces different heterogeneity weighting and different rationale. 100% of scorecard cells carry at least one source ID. Blocking the GTEx API produces "score withheld — expression evidence unavailable", not a default.

### Phase 6 — End-to-end and SME validation

- `query_agent.py` CLI, `deploy.py` to Vertex Agent Engine, health-check banner, cost and latency budget.
- Prompt-injection test: a PMC paper containing an embedded instruction must not be executed. Retrieved documents are data, never instructions.

**Golden-path scenario.** Input: *"Compare FOLH1, STEAP1, TMEFF2 and DLL3 as Lu-177 radioligand targets in metastatic castration-resistant prostate cancer."* Expected: per-target expression profile, OAR panel with `not_measured` flags where applicable, trial landscape, internalisation and shedding with citations, heterogeneity metrics, and an explicit ranking with rationale — every claim carrying a source ID and data version stamp.

**SME validation:**
- Rank concordance: three SMEs and the agent rank six targets in one indication. Spearman ρ ≥0.7, noting inter-rater ρ as the realistic ceiling.
- Time-to-brief: measure *agent time + SME correction time* against *manual time*, at equal or better accuracy. This is the metric that justifies the project.
- Blind accuracy audit: 10 briefs, every factual claim marked correct / incorrect / unverifiable. Acceptance: ≥95% correct, **zero fabricated citations or NCT IDs**, ≤5% unverifiable.

## 8. Regression Gates

Wire G1–G5 into CI; all are automatable. G6 runs at milestones.

| Gate | Requirement | Blocks |
|---|---|---|
| **G1 — No fabrication** | Zero fabricated NCT IDs, PMIDs or uncited numerics | Everything |
| **G2 — Hard gates fire** | MKI67/TP53 fail accessibility; GAPDH fails selectivity; FOLH9 abstains; FAP is stromal | Any SME use |
| **G3 — Determinism** | Score variance = 0 over five runs; identical API payloads | Use in decision documents |
| **G4 — Traceability** | 100% of scorecard cells sourced and version-stamped | Use in decision documents |
| **G5 — Missing ≠ zero** | Every OAR distinguishes `not_measured` from `not_detected` | Any safety-relevant claim |
| **G6 — SME concordance** | ρ ≥0.7; ≥95% factual accuracy | Production rollout |

## 9. Risk Register

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| C2S returns confident ranks for genes absent from the atlas | High | Severe | Membership check before endpoint call; concordance gate against local fallback |
| Scoring stays in the prompt because it ships faster | High | Severe | Phase 5 exit gate is binary — no scorecard ships until variance = 0 |
| TxGemma confabulates internalisation rate constants | Medium | High | Citation-or-abstain enforced in `guards.py`, not prompt text |
| HPA Pathology Atlas T-side treated as a matched tumour/normal study | Medium | High | Caveat string on every T/N claim; evidence tier caps achievable score |
| `predict_toxicity` output leaks into the scorecard | Medium | Medium | Excluded at schema level — no scorer axis reads it |
| Gemini preview model changes mid-project | Medium | Medium | Pinned model ID; change triggers full regression re-run |
| Four Vertex endpoints make cold-start latency unacceptable | Medium | Medium | Parallel gather; enrichment endpoints non-blocking; disk cache |
| Scope creep into dosimetry or chelate chemistry | Low | Medium | Boundaries in the opening section are fixed — hold them |
